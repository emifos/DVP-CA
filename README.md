## **Installation**

1. Clone the repository

```bash
  git clone https://github.com/emifos/DVP-CA.git
```

2. Navigate to the project folder

```
 cd DVP-CA
```

3. Open the project in code editor (VS Code)

```
 code .
```

4. Install dependencies

```
npm install
```

5. Start development server

```
npm run dev
```
